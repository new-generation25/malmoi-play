# 말모이 작전 — 관객참여 퀴즈 데모

무대 스크린과 관객 스마트폰을 한 화면에서 보여주는 연출용 데모입니다.
스크린에는 접속 인원과 «말모이 원고 복원율» 게이지만 뜨고, 문제 풀이는 폰 화면에서 진행됩니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 본체. 이 파일 하나만 열면 동작합니다(Vercel이 서빙하는 파일). |
| `qrcode.js` | QR 생성 라이브러리 (Kazuhiko Arase, MIT) |
| `build.js` | `index.html` + `qrcode.js` → `malmoi-artifact.html` 로 합치는 빌드 스크립트 |
| `malmoi-artifact.html` | Artifact 배포용 단일 파일. 웹 배포에는 쓰이지 않습니다. |

## 배포

Vercel 정적 배포입니다. 빌드 설정이 필요 없습니다(프레임워크 없음 / 빌드 명령 없음 / 루트 디렉터리 그대로).
`main` 브랜치에 푸시하면 Vercel이 자동으로 재배포합니다.

## 두 가지 화면

| 주소 | 화면 |
| --- | --- |
| `/` | **무대 스크린.** 접속 인원 + 복원율 게이지 + 폰 목업. 진행자가 띄웁니다. |
| `/?p=1` | **관객 폰 전용.** 무대 스크린 없이 퀴즈만 전체화면. QR이 이 주소를 가리킵니다. |

QR은 **현재 페이지 주소 + `?p=1`** 을 가리킵니다. 배포된 주소에서 열면 QR도 그 주소를
가리키므로 관객이 스캔하면 폰 전용 화면이 열립니다. `localhost`로 열면 QR도
`localhost`가 되어 관객 폰에서는 열리지 않습니다.

폰 전용 모드에서는 가상 관객 시뮬레이션과 «순사 급습» 연출이 돌지 않습니다.
관객마다 자기 게이지가 따로 뜨면 무대 화면과 숫자가 어긋나기 때문입니다.

> **서버가 없습니다.** 관객 폰의 응답은 무대 스크린으로 전달되지 않습니다.
> 무대의 게이지는 시뮬레이션된 49명 + 진행자 폰 목업으로만 움직입니다.
> 실제 실시간 집계가 필요하면 별도의 서버/DB가 필요합니다.

## 로컬 실행

```
npx serve . -l 4321      # http://localhost:4321
node build.js            # malmoi-artifact.html 다시 생성
```

## 연출 메모

- 게이지는 모든 응답이 도착해도 **90%에서 멈춥니다**(목표선 100%에는 닿지 않음).
- **스크린을 클릭하면 «순사 급습» 연출**로 게이지가 70%로 떨어집니다. 공연 중 1회만 발동하며,
  게이지가 75% 아래일 때는 발동하지 않습니다. 방해 이후에도 남은 응답이 70→90% 구간을
  다시 채우므로 결말은 항상 90%입니다.
- 관객 49명은 각자 다른 속도로 응답하도록 시뮬레이션됩니다(서버 없음).
