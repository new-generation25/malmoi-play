# 말모이 작전 — 공연용 연출 페이지

> **다른 환경에서 이어받으셨다면 [CONTINUE.md](CONTINUE.md), 공연 운영을 맡으셨다면 [HANDOVER.md](HANDOVER.md) 를 먼저 읽으십시오.**
> 공연 전 반드시 해야 할 작업(Supabase 테이블 생성)이 남아 있습니다.

한 공연에서 쓰는 두 장면을 각각 독립된 웹 페이지로 담았습니다. 진행자가 장면마다
해당 URL을 직접 엽니다. 서버 없이 브라우저만으로 동작하는 정적 페이지입니다.

## 페이지

| 주소 | 장면 | 누가 봄 |
| --- | --- | --- |
| `/` | **관객참여 퀴즈 — 무대 스크린.** 접속 인원 + «말모이 원고 복원율» 게이지 | 진행자(무대) |
| `/?p=1` | **관객참여 퀴즈 — 폰 전용.** 무대 스크린 없이 퀴즈만 전체화면 | 관객(QR 접속) |
| `/dm.html` | **덕이 ↔ 아란 DM 채팅 연출.** 카카오톡 스타일 대화 재생 | 진행자(무대) |

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 퀴즈 본체. 무대/폰 두 모드를 `?p=1` 유무로 분기합니다. |
| `dm.html` | DM 채팅 연출. 완전 독립 실행(외부 리소스 없음). |
| `qrcode.js` | QR 생성 라이브러리 (Kazuhiko Arase, MIT) |
| `build.js` | `index.html` + `qrcode.js` → `malmoi-artifact.html` 로 합치는 빌드 스크립트 |
| `malmoi-artifact.html` | Artifact 배포용 단일 파일. 웹 배포에는 쓰이지 않습니다. |

## 배포

Vercel 정적 배포입니다. 빌드 설정이 필요 없습니다(프레임워크 없음 / 빌드 명령 없음 / 루트 그대로).
`main` 브랜치에 푸시하면 Vercel이 자동으로 재배포합니다.

## 관객참여 퀴즈 (`/`, `/?p=1`)

무대와 관객 폰은 **완전히 분리**되어 있습니다. 무대에는 게이지만, 관객 폰에는 퀴즈만 뜹니다.

- QR은 **현재 페이지 주소 + `?p=1`** 을 가리킵니다. 배포된 주소에서 열면 관객이 스캔했을 때
  폰 전용 화면이 열립니다. `localhost`로 열면 QR도 `localhost`가 되어 관객 폰에서는 안 열립니다.
- **무대**: 화면을 클릭하면 작전이 시작되고, 관객 응답이 도착하는 대로 게이지가 오릅니다.
  응답이 쌓일수록 상승폭이 줄어 **90%에 수렴**합니다(목표선 100%엔 자연히 닿지 않음).
- **순사 급습**: 무대 화면 클릭 또는 **7** 키로 게이지를 70%로 떨어뜨립니다. **진행자가
  원하는 순간 언제든** 발동합니다. 아직 70%에 못 미친 시점에 누르면 게이지가 올라가는
  모순이 생기므로, 그럴 땐 현재 값의 3/4 지점으로 떨어집니다(항상 내려감).
  급습 뒤에도 이어지는 응답이 하락 지점→90% 구간을 다시 채웁니다.
- **관객 폰**: 8문제를 풀면 «무대 화면을 봐 주세요» 안내가 뜹니다. 관객 폰에서는
  진행자 연출(급습·게이지 조작)이 일절 동작하지 않습니다.

### 실시간 집계

관객 폰의 응답이 **실제로 무대 스크린에 반영됩니다** (Supabase). 설정법은 [SETUP.md](SETUP.md).

```
관객 폰 (/?p=1)  ──POST──▶  Supabase  ◀──1초 폴링──  극장 스크린 (/)
```

게이지는 실집계를 따라 움직이되, 응답이 쌓일수록 상승폭이 줄어 90%에 수렴합니다.
관객이 몇 명이든 거꾸로 가거나 도중에 멈추지 않습니다.

**진행자는 언제든 게이지를 직접 잡을 수 있습니다.**

| 키 | 동작 |
| --- | --- |
| 클릭 / Space | 시작 → 순사 급습 → 작전 완료 → 리셋 (한 단계씩) |
| **1** | 의견 1건 — 1%씩 올린다 (말풍선·소리까지 진짜 응답처럼) |
| **7** | 순사 급습 — 70%로 떨어뜨리고 거기서 다시 상승 |
| **9** | 90% 고정 |
| **0** | 100% 고정 (완전 복원 연출) |
| **A** | 개입 해제 (실집계로 복귀) |
| **E** | 즉시 종료 (어떤 상태에서든) |
| **H** | 진행자 바 숨기기 |

> **Supabase를 설정하지 않으면** 무대에 «시뮬레이션» 배지가 뜨고 가상 관객 50명으로
> 동작합니다. 리허설에는 그대로 쓸 수 있지만, 실제 공연에서는 이 배지가 뜨지 않는지
> 반드시 확인하십시오.

## DM 채팅 연출 (`/dm.html`)

덕이(노란 말풍선, 무대에서 타이핑) ↔ 아란(회색 말풍선, «입력 중» 후 도착)의 대화를 재생합니다.
화면을 클릭하면 시작하고, 이후 클릭할 때마다 한 대사씩 진행됩니다.

| 조작 | 동작 |
| --- | --- |
| 클릭 / Space / → | 다음 (타이핑 중이면 즉시 완성) |
| ← / Backspace | 뒤로 |
| R | 처음부터 |
| F | 전체화면 |
| `+` / `−` | 타이핑 속도 |
| `[` / `]` | 음량 |
| H | 진행자 힌트 숨김/표시 |

효과음은 코드로 합성하며(외부 파일 없음), 첫 클릭 이후 소리가 켜집니다.
화면 하단 진행자 힌트는 관객석에서 안 보이도록 프로젝션 밖(H로 토글)에 둡니다.

## 로컬 실행

```
npx serve . -l 4321      # http://localhost:4321
node build.js            # malmoi-artifact.html 다시 생성
```
